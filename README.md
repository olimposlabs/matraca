# Matraca

Matraca é uma plataforma em descoberta para desenvolver oratória por meio de gravações, avaliações por IA e prática orientada. O produto atenderá usuários avulsos e organizações parceiras com experiência white label e isolamento por organização. O escopo da implementação está em definição.

O repositório começa com as diretrizes de engenharia. Ainda não há aplicação, manifesto de dependências ou setup confirmado.
